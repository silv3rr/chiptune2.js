# Web music players

- https://deskjet.github.io/chiptune2.js/ the original
- https://drsnuggles.github.io/chiptune/ chiptune3
- https://chiptune.app/ chip player js - nice msdos-like gui (game music)
- https://github.com/soltune/chip-player-js-docker/ chiptune.app docker image
- https://mod.haxor.fi/Heatbeat/mod.rakkorules/ js mod/s3m/xm player (webaudio-mod-player)
- https://www.wothke.ch playmod and other js players
- https://coolmodfiles.com/ web player with modern look (chiptune2 based)
- https://modsamplemaster.thegang.nu/ mod indexer
- https://webamp.org/ winamp in html5/js
- https://keygenmusic.tk lots of keygen music
- https://scriptracker.cheerful.nl/ player with st3 gui
- https://med.planet-d.net/demo/web/modplayer/ ModPlayerJS (older)
- https://warpdesign.github.io/modplayer-js/ Modplayer-js (material ui)
- https://atornblad.github.io/js-mod-player/ JS-MOD-player (with blogs how it was made)
- https://github.com/MelissaAutumn/m-mod-player m-mod-player (libopenmpt)
